# PRD: Greeting experience

## Problem Statement

The app shell has no welcome surface, so users land on an empty home route
with no project context.

## Solution

Add a greeting banner backed by the registered project name, then let users
dismiss it once they have seen it.

## User Stories

1. As a user, I want a greeting banner on the home route, so that the app feels welcoming.
2. As a user, I want the banner to show the project name, so that context is clear.
3. As a user, I want to dismiss the banner, so that it does not stay forever.
